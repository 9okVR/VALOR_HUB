# VALOR HUB

Multi-game script hub. One loader detects the game and runs the right panel.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/9okVR/VALOR_HUB/refs/heads/main/ValorHub_Loader"))()
```

A key is required. Get one in the Discord: https://discord.gg/GSAHydBefQ

Supported: Volleyball Legends · Blox Fruits · Fisch · Grow a Garden · Murder Mystery 2 · RIVALS · Bedwars · Keyboard Escape · Steal An Egg · Huss Valley · (Universal fallback for anything else)

Usage stats: the loader reports your Roblox username, the game and server you are in, your executor and device, which panel switches are on (and the last ones you changed), the panel's error count, the kick or disconnect message Roblox shows you, game results the panel counts (e.g. Volleyball touches), and your FPS and ping, so we can see what is used, fix what breaks and catch game updates or kick waves fast. Problem reports you send from a panel's Report tab go to us with the same details. Nothing else is collected.
